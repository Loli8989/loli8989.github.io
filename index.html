🚀 What Is 1401?

1401 is a guided installer designed for everyday Windows users who want to try macOS on regular PC hardware. Behind the scenes it prepares the setup files, configures the OpenCore boot environment, and keeps the technical parts out of your way. Instead of reading long technical guides and copying files by hand, you work through a clear sequence of screens that explain what is happening and what to do next.

The application is built around three ideas: it should be easy to understand, it should not hide anything from you, and it should let you stop at any point without damaging your Windows installation. Every stage of the process is shown in plain language, and every action you take is something you can review before it happens.

Because the project is distributed through GitHub, each version is published as a release you can browse, download, and keep for later. If you ever need to start over, you simply run the app again from the same page.

💻 Before You Begin

Take a few minutes to prepare. Having these things ready makes the whole process much smoother.

  • A Windows PC running Windows 10 or Windows 11 (64-bit). Older versions of Windows are not recommended.
  • At least 8 GB of free space on a USB drive. The drive will be prepared by the app, so use one you do not mind erasing.
  • Around 40 GB of free disk space on the computer if you plan to keep a macOS installation alongside Windows.
  • A stable internet connection. The installer needs to fetch files while it works.
  • Administrator rights on your Windows account. This is needed to prepare removable media and boot files.
  • A backup of anything important. Working with boot settings is always safer when you have a copy of your files.
A word of caution: installing an operating system is a change to your computer. Do not unplug the USB drive or shut down the machine while the app is actively working. If you are unsure at any screen, stop and read the explanation before clicking continue.

No. The application is built for people who have never touched a bootloader before. Everything is explained in ordinary language.

Will this delete my Windows installation?

No. 1401 prepares the setup files on removable media and does not wipe your existing Windows system. As with any system-level change, keep a backup of your important files.

🛠 Troubleshooting Tips

  • The download stops partway through. Delete the partial file and start the download again from the releases page.
  • Windows blocks the file from opening. Right-click the file, open its properties, and look for the option to allow it to run. Then double-click it again.
  • The app cannot see your USB drive. Unplug it, try a different USB port — preferably one directly on the computer rather than a hub — and plug it back in.
  • A screen seems frozen. Wait a few minutes before doing anything. Large file operations can look stuck while they are still working.
  • Something fails repeatedly. Note the exact message on screen. The release notes on the download page often describe known issues and their fixes.
